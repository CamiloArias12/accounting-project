# accounting-project

## Descripción

Proyecto de contabilidad.

## Stack

- Node.js / Next.js
- Python

## Requisitos

- Node.js 20+
- Python 3.11+

## Instalación

```bash
# Dependencias de Node
npm install

# Dependencias de Python
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Uso

```bash
npm run dev
```
